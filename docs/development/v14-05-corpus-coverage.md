This is the current corpus inventory for V14-05, dated 29 October 2026. It
supersedes the **inventory table** in the historical V14-00 corpus document;
that document's original fixture and rights limitations remain applicable.

entry, no Tier 2 entries, eight approved local-analysis Tier 3 references and

## Coverage boundaries and retained external gaps

The new corpus adds reproducible independent agreement for different supported
shapes, rather than another copy of the original seven workload messages.
`tests/test_v145_corpus.py` checks all 28 complete capture-to-enrichment outcomes,
strict fields, categories, reasons, packet ordering, capture offsets, VLAN joins,
record denominators and exclusion of hostile-looking UA application strings.
Its **32 unique tests passed**, with no failures/errors/skips. Focused Ruff lint,
format checks and strict mypy over the two added Python files pass. The initial
test run exposed one test-authoring typo (`packet_count` instead of the actual
`packets` field); correcting it changed no fixture expectation or product code.

Existing tests provide complementary classes: malformed lengths and headers,
coalesced records, segmentation, wrong/nonstandard ports, unrelated EtherTypes,
resource boundaries and privacy in `test_protocol_enrichment.py`,
`test_protocol_enip_s7.py`, `test_protocol_iec_opc_dnp.py` and the V14-01 audit
tests. These references describe existing coverage; the focused 32-test result
does not claim those entire suites were rerun by the corpus agent. Broader
integration and resource results belong to the consolidated V14-05 handoff.

The eight existing local Tier 3 files retain the pinned hashes, sizes and framing
listed in [external evidence](v14-external-corpus.md). Main-agent revalidation
is recorded in `output/v145/existing-external-integrity.json`; no new external
bytes were acquired or copied into Git. The previous five supported captures'
615 positive records / 2,194 selected comparisons remain **historical 4.6.7
results**, not a newly executed differential comparison.

Read-only candidate research on 29 October confirmed that the
[Wireshark DCP index](https://wiki.wireshark.org/PROFINET/DCP) still links
`ChangeIPUsingDCP.pcap`, and the
[sample index](https://wiki.wireshark.org/SampleCaptures) still has IEC-104
examples. Neither inspected index established a per-capture redistribution
grant or a newly approved immutable payload digest. No candidate payload was
downloaded. The PCAP4SICS page request timed out; its earlier acquisition-size
assessment was not revalidated and is not presented as a fresh result.
The existing Modbus LFS-pointer/rights and oversized-archive blockers remain
documented, without inventing new hashes or claiming external Modbus/DCP/IEC104
success. DLT_NULL and Linux SLL remain explicit unsupported linktypes; no
conversion or support extension was made to manufacture positive results.

Synthetic parser correctness, synthetic independent-tool agreement, external
parser examples, unsupported framing and production validation are distinct.
None of these tests establishes real plant validation, certification, reviewer
authentication, physical ownership, safe process behavior or general immunity
to hostile inputs. This finite program does not replace the planned pre-v1.5
product-wide adversarial campaign.

## Reproduction

From the repository using an interpreter with the current package installed:

```powershell
python -m tools.v145_corpus --output output/v145-corpus/integrity.json
python -m pytest tests/test_v145_corpus.py -q --junitxml output/v145-corpus/focused.xml
python -m ruff check tools/v145_corpus.py tests/test_v145_corpus.py
python -m ruff format --check tools/v145_corpus.py tests/test_v145_corpus.py
$env:MYPYPATH = 'src'
python -m mypy tools/v145_corpus.py tests/test_v145_corpus.py
```

The ordinary tests never invoke TShark or networking. To reproduce the
independent receipt, use its ordered `arguments` and `fields`, replace `INPUT`
with the exact verified capture, append `-e FIELD` for every field and invoke
the recorded TShark version. Compare each ordered row by `frame.number` using
the explicit allowlisted translations in `_independent_fields` in the test.
Do not replace the historical tool version in place when using another version.
Local receipts: `output/v145-corpus/focused.xml`, `integrity.json` and
`tshark-fields.txt`. Raw third-party references remain under ignored `output/`.
