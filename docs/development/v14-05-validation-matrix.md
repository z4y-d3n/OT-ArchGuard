resource boundaries, and composed historical/replay/publication invariants.
Use exclusive new filenames for the three agents; the integrator owns existing
source, public inventories, matched performance evidence and final handoff.

an actual defect before considering a narrow correction and its historical
identity consequences. Preserve the approved semantic HTML presentation.

history-v2 lifecycle with the V14-02P consumer supplement, drift-v1 contract,

## Acceptance method

Run focused independent tests during implementation. Once integrated, freeze
runtime/tests/tooling, run one complete offline source suite, global Ruff and
strict mypy, dependency checks, exact wheel/sdist and installed inventories,
immutable native/presentation compatibility, frozen consumers and walkthroughs.
Measure matched fixed inputs with the same interpreter, repeated untraced
trials and separate allocation trials without concurrent test suites. Preserve
actual ranges and slower outcomes. Final evidence must classify A01–A20 as
PASS, PASS WITH DOCUMENTED LIMITATION, FAIL or NOT EXECUTED.

This finite hardening program is neither production deployment validation,
industrial certification, penetration testing nor the separate pre-v1.5 public
adversarial campaign. Local review claims remain unauthenticated; hashes bind
content and do not confer authority. Existing single-writer and no-TCP-reassembly
limits remain.
