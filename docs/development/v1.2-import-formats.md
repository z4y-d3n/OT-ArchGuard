# Import format support — Gate V12-01

| Input | Current support | Limitations |
| --- | --- | --- |
| CSV / TSV | Bounded table inspection, explicit field mapping, owner review and inventory emission | One header at physical line 1, one table, no dialect/encoding guessing |
| Native YAML schema 1 | Existing validate/check/trace/exposure/compare commands | No reinterpretation or automatic integration |
| YAML / JSON control files | Versioned mapping, draft and decision documents | Strict existing YAML subset, bounded input, no includes or executable tags |
| XLSX / JSON inventories | Planned V12-02 | Not accepted by the source adapter |
| draw.io / GraphML | Planned V12-03 | Not accepted |
| VSDX / PDF / DOCX / PPTX / text tables | Evaluate V12-06 | Not accepted; no OCR |
| Vendor configuration | Deferred | No ACL/NAT inference |

CSV subset: UTF-8 with optional BOM, or explicit CP1252; `.csv` uses comma,
`.tsv` uses tab. Explicit one-character delimiters are allowed except quotes,
newlines and control characters other than tab. Quoted multiline cells and doubled
quotes are supported. Empty data rows, ragged rows, duplicate/blank headers,
binary controls and malformed Unicode/quotes are rejected. The reserved header
`<<` is rejected because the shared control-document loader forbids merge keys.
Formula-like values
are inert evidence with warnings. File suffix selects a permitted text format;
the parser also verifies its bounded textual/table structure. A renamed archive,
XML or other binary document is not treated as a valid inventory automatically.

Ceilings: 1 MiB source, 1,000 data rows, 64 columns, 32,000 cells, 4,096 characters
per cell/header, 200 diagnostics. Profiles/drafts/decisions use the existing
5 MiB, depth-32, 200,000-event YAML loader ceilings. Generated drafts are checked
against all three control-document budgets before publication; rich per-cell
provenance can reach the event ceiling before the 1,000-row ceiling. The native model retains
all existing schema/resource limits. A diagnostic overflow rejects the operation.
These are rejection ceilings, not measured capacity promises.
