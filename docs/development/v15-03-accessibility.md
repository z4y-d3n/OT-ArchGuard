# V15-03 accessibility evidence and limits

Structural changes: exact current-page versus family semantics, labelled native
table/detail pagination, current-page paragraph, explicit record range, existing skip
target made programmatically focusable without an extra Tab stop. Existing visible
focus CSS, native links/details, named keyboard-scrollable table regions, scoped
headers, captions, h1, English UI, status text and full identifiers are retained.

Actual browser attempt used the generated fictional local `file:` report in the
available in-app browser. Its security policy rejected the protocol (only http/https
allowed). No alternate surface/server workaround was attempted. Consequently real
keyboard, scroll focus, disclosure activation, fragment focus, zoom, responsive
layout and print are **NOT_TESTED**, not PASS. No formal accessibility claim.
