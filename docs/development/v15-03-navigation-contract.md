# V15-03 navigation contract

Capture family entrypoints keep their original filenames. `aria-current=page`
on a link means its href names the containing document exactly. A main/related
family entrypoint uses `aria-current=true` on another document in that family;
it denotes the current navigation item, never an exact page or approval.
A page has exactly one active family entrypoint across the main/related groups.
A separately labelled
pager identifies its current page with a non-link paragraph. Main has `id=main` and
`tabindex=-1` for the existing skip link; this adds no sequential Tab stop.

Listings use the existing `stem.html`, `stem-2.html` names, except evidence index
continuations retain `evidenceindex-N.html`. Evidence detail batches retain
`evidence-N.html#flow-ID`; index and details are different page families.
Both pagers state Page N of M and Records A–B of total; an empty listing is
Page 1 of 1, Records 0–0 of 0. Previous/next links exist only for real adjacent
documents. The first/last batch has no off-boundary link.

Overview → observed address → aggregate → finding → retained flow evidence →
reviewed association → communication remains supported with exact existing
IDs. ARP target references do not establish observed target presence. Reviewed
association is separate from captured evidence; model reachability is separate
from deployed enforcement. Unsupported, incomplete, unmapped, uncertain and
not-evaluated outcomes retain their original qualified text and canonical codes.
No link invents authorization, safety, packet payload or absent retained evidence.

Every canonical JSON byte, row anchor, flow ID, packet reference, reviewer decision
and detail record remains available. Navigation is linear and bounded by existing
page/output limits; failed publication never becomes a partial successful report.
Escaping, bidi disclosure, path masking, CSP and offline inert output remain.

Architecture, capture and historical sites retain independent publication and
identity contracts. No absolute filesystem links or fabricated cross-site ancestry
are added. Historical finding/evidence/scope/replay/authority links remain as before.
Seven vertical Major limitations remain unchanged. Import provenance and explicit
review precede validated native declarations; no new integration is implied.
