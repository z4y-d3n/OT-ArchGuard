# v1.2 development roadmap

The immutable released baseline is v1.1.0. This program does not authorize any
push, remote PR, publication, tag change, new dependency download or live network
interaction. Gate results describe locally tested development only.

| Gate | Slice | Acceptance focus |
| --- | --- | --- |
| V12-01 | CSV/TSV evidence foundation | Explicit mappings, review, provenance, native validation, bounded hostile inputs |
| V12-02 | XLSX and JSON | Selected sheets, cached formula limitations, offline NetBox subset, identity conflicts |
| V12-02R | Remediation before graphical import | Exact numeric evidence, renewed structured review, parser bounds and sanitized review packaging |
| V12-03 | draw.io and GraphML | Bounded XML/decompression, grouping, evidence-only connections |
| V12-04 | Multi-source reconciliation | Order-independent matching and explicit conflict decisions |
| V12-05 | Architecture Explorer | Stable anchors, zone views, accessible legends, policy/trace/provenance crosslinks |
| V12-06 | Document evidence and compact Explorer | Restricted TXT/Markdown/DOCX/PPTX; PDF/VSDX deferred; bounded grouped evidence pages |
| V12-07 | Quality and visual comparison | Completeness diagnostics and exact compare-aligned changes |
| V12-08 | Integration | Wheel installs, offline checks, platform CI, resource budgets, release readiness |

V12-01 is locally accepted: two Windows installed-wheel runs passed 1,438 tests
each. See the [gate report](gate-v12-01.md) for exact scope, evidence and limits.
V12-02 is locally accepted: both Windows versions passed 1,598 full tests,
including 160 new cases. It implements the restricted structured subsets in its
[gate report](gate-v12-02.md). V12-03 implements the bounded graphical subsets in
its [gate report](gate-v12-03.md); exact local acceptance is source-bound in the
ignored final run. V12-04 implements Import Projects, indexed reconciliation,
guided review and native emission; its [gate report](gate-v12-04.md) describes the
source-bound local verification. V12-05 implements the local offline Architecture
Explorer; its exact acceptance status is recorded in [gate-v12-05.md](gate-v12-05.md)
and the final source-bound ignored receipt. V12-06 implements documentary subsets
and Explorer compaction under its [gate report](gate-v12-06.md) and final source-bound
receipt. V12-07 onward remain unimplemented.

V12-02R supersedes V12-02 acceptance for continuing development. Its
[remediation report](gate-v12-02r.md) describes numeric-contract migration,
independent fresh verification and remaining local-platform limits. The final
machine-readable acceptance record binds the tested public-source identity;
V12-03 starts only after that run passes. This does not authorize implementation
of V12-03 in the remediation task or claim hosted Ubuntu/macOS verification.

Complete and review each coherent slice before expanding. Advanced documents and
vendor configuration adapters are deferred because safe extraction and precise
semantics cost more than extension recognition. OCR, live discovery and cloud
interpretation are outside this program. Future visuals should distinguish source
connections, owner declarations and exact analytical results, with useful text
evidence even when scripts are disabled.

Stable v1.2.0 publication remains blocked until the exact final release candidate
passes actual hosted Windows/Ubuntu/macOS × Python 3.12/3.14 runs. Record each
runner OS, Python, commit, workflow-run identity, test totals/failures/skips,
artifact identities, installed-module verification and runtime offline guard.
Local V12-04 acceptance cannot waive this prerequisite. No hosted run was
authorized or dispatched by the V12-04 task; publication requires separate approval.
